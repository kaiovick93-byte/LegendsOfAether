# Floresta Ancestral — Kit aprovado

Este diretório contém o kit visual aprovado pelo usuário para a Floresta Ancestral/Antiga da Estrada Velha.

- O master sheet aprovado foi preservado sem alteração.
- Os PNGs individuais são derivados do master aprovado e possuem fundo transparente.
- Total: 49 assets individuais.
- Este round **não integra a floresta ao mapa**.
- A integração só pode ocorrer após mapear exatamente o polígono vermelho da referência do usuário, conforme `AGENTS.md` e `PROJECT_RULES.md`.
- Nenhum asset deste diretório pode ser usado fora da área marcada sem pedido explícito.
